**Highlights**

- Implemented authentication and JWT-based security.
- Built services for profiles, posts, feeds, reels, interactions,
  and real-time chat.
- Worked with Spring Boot, MongoDB, PostgreSQL, and Redis.
- Explored inter-service communication, service isolation,
  and distributed application architecture.
- Used Docker and Cloudflare for supporting infrastructure
  and media storage.

**Tech:** Java, Spring Boot, Spring Security, MongoDB, PostgreSQL,
Redis, Docker, WebSockets

### 2. Event-Driven TCP Server

A low-level networking project focused on understanding how servers
handle concurrent connections and network I/O.

**Highlights**
- Explored TCP sockets and the Linux networking model.
- Worked with non-blocking sockets and the `epoll` event mechanism.
- Studied connection state, socket readiness, and event loops.
- Investigated concurrency, resource management, and server
  performance under load.
- Working toward a Rust implementation using asynchronous
  and event-driven I/O.

**Tech:** C, Linux, TCP/IP, Sockets, `epoll`, Rust

[Explore my repositories](https://github.com/deepakSingh023)
